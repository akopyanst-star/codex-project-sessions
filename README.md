# Codex Project Sessions (unofficial)

Неофициальное дополнение для VS Code. Оно не связано с OpenAI и не одобрено OpenAI. Работает поверх официального расширения OpenAI Codex (`openai.chatgpt`), которое должно быть установлено. Скриншота нет.

## Переезжаете с Claude Code?

Есть пошаговая инструкция, которую выполняет сам Codex: [PEREEZD.md](PEREEZD.md). Напишите в чат Codex одну строку:

```
Прочитай https://github.com/akopyanst-star/codex-project-sessions/blob/main/PEREEZD.md и выполни переезд по шагам.
```

## Что умеет

- Отдельный значок в левой панели (Activity Bar).
- `Account & Usage`: локальные лимиты Codex (5 часов, 7 дней), процент расхода и время до сброса. Данные берутся из локальных событий `token_count`, которые пишет сам Codex; API-ключ не нужен, `auth.json` не читается.
- `Session Manager`: список чатов только текущего проекта (чат попадает в список, если его рабочая папка совпадает с открытой; вложенные проекты не смешиваются, например `my-app/backend` виден только когда открыт именно он).
- Клик по чату открывает его во вкладке редактора. Кнопка `+` создаёт новый чат во вкладке.
- Поиск, фильтр активных сессий, пользовательские группы (хранятся отдельно для каждого проекта).
- Удаление из списка не стирает переписку; вернуть можно командой `Restore Removed Chats`.
- Названия берутся из индекса Codex (`~/.codex/session_index.jsonl`). Пустые заготовки без сообщений в списке не показываются.

## Установка

1. Скачайте файл `.vsix` на странице Releases.
2. VS Code -> Extensions -> меню «...» -> `Install from VSIX...` -> выберите файл.
3. Выполните `Developer: Reload Window`.

## Настройка патча (по умолчанию выключен)

Настройка `codexProjectSessions.patchOfficialExtension` (по умолчанию `false`). Если включить, дополнение правит файлы официального расширения OpenAI Codex:

- в `package.json` официального расширения кнопка в заголовке редактора открывает новый чат во вкладке;
- в скомпилированном webview маршрут `/first-run` ведёт на обычный экран нового чата, чтобы не повторялись экраны первого запуска.

При первом запуске дополнение один раз спросит, включить ли патч. Делайте это на свой риск: после обновления OpenAI Codex патч применяется заново для новой версии, а если структура файлов изменилась, вы увидите предупреждение, что патч применён не полностью. Перед правкой рядом с файлом сохраняется копия `*.codex-project-sessions-<версия>.bak`, запись идёт через временный файл и переименование.

Без патча всё остальное (список сессий, лимиты, группы, открытие чатов) работает.

### Как откатить

Выполните команду `Restore official Codex extension files` (Command Palette). Она вернёт из `.bak` все файлы текущей версии `openai.chatgpt`, удалит `.bak`, выключит настройку патча и предложит `Reload Window`. Если расширение OpenAI обновилось, то файлы новой версии и так чистые (патч привязан к версии), а при желании выключите настройку вручную.

## Проверено

- **Windows** - проверено, автор пользуется сам.
- **Mac** - скорее всего, тоже работает (пути в коде собраны для обеих систем), но не тестировалось. Если пробуете на Mac - напишите в Issues, что получилось.
- **Linux** - не проверялось.
